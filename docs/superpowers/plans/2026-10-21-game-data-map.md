# Мапа з файлів гри — план 5

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** дані мапи — з файлів гри; сторонні джерела мапи лишаються лише винятками там, де в серверних файлах нема пікселів (тайли, спрайт іконок TH.GL). Етап **5a** (зараз): місця полів меланжу Глибокої пустелі для **всіх 17 розкладок** з файлів гри — виняток Red-Blink (разова копія гравців, лише розкладки 1–2) прибирається. Етап **5b** (далі, окремим погодженням): точки мапи й ресурси з «контент-блоків» гри, ігрові типи точок без відповідності TH.GL, розклад розкладок ГП з гри.

**Spec:** `docs/superpowers/specs/2026-10-21-game-data-drivers-design.md` §4.1 (`spice`, `resources`, `markers`, `ddLayouts`), §4.6 (координати), §7 етап 4; правила користувача: без таблиць відповідності, сторонні джерела — геть, крім винятків.
