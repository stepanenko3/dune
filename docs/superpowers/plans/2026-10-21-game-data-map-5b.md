# Мапа з файлів гри — план 5b

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** точки мапи з файлів гри з ігровими типами (без відповідності TH.GL) і розклад розкладок Глибокої пустелі з гри. Мапа лишається на TH.GL як основне, доки файли гри не покриють усе (ресурси, міста); до того мапа з файлів гри — друге джерело групи «Мапа» з порівнянням.

**Spec:** `docs/superpowers/specs/2026-10-21-game-data-drivers-design.md` §4.1, §4.6; план 5 (`2026-10-21-game-data-map.md`) Task 3; дослідження — side-session-notes/…/map-research.md («Plan 5b research»).

## Знахідки (збірка 2160922)
- Хаґґа: регіони `SOC_1/SubLevels/Survival_1_<Регіон>.umap` → `BP_TerrainBlockActor_C` (блок + групи + перевизначення вкладених) → `TerrainBlockDataAsset` (рівні блоку з групами, вкладені блоки) → актори рівнів. Прототип обходу збігся з TH.GL до сантиметра (печери 95/98, табори 425/435, аванпости 70/70, екоlab 14/14, уламки 13/13, січі 8/8).
- Тип точки — тип мітки гри (`CDT_FullscreenMapMarkers`, 225 рядків: назва з таблиці рядків, тег фільтра `MapMarkers.*` → група, текстура іконки). Іконка — файл awakening.wiki з іменем текстури (те саме правило, що для будівель). Точки без мітки — клас гри (`TemporaryLootSpawner` з типом контейнера, `BP_PentashieldKey_C`, `BP_VehicleSpawner_*`…).
- Розклад ГП: `DefaultGame.ini [CoriolisSubsystem]` — старт 2024-12-03 05:00, цикл 7 днів, `m_CycleSeeds` (122), регіональний зсув; номер = індекс у списку розкладок `WorldLayoutSubsystem`.
- Ресурси: групи точок загальні (`Minerals`, `Scrap`…); конкретний ресурс — карти тепла (`DT_ResourceTypes` + `DA_*DistributionGroup` → `HeatMapData`). Окремий етап.

## Global Constraints
- Файли гри й сирі експорти — лише в `GD_WORK`; у пакеті — лише похідні дані (координати, ігрові id, ключі перекладів). Без таблиць відповідності; типи — ігрові id.
- Робоча копія, міграції — додаткові й ідемпотентні; живий — лише після перевірки на `dune_preview`.
- Мапа TH.GL лишається основною, доки користувач не перемкне групу «Мапа».

## Review Focus
1. Блок, рівень чи вкладений блок, якого нема в експорті — розділ з помилкою (видобувач), не мовчки менше точок.
2. Новий патч змінює кількість точок на >50 % — розділ на утриманні (правило реєстру), а не порожня мапа.
3. Порівняння TH.GL ↔ файли гри за позицією (ключ — мапа й координати), тип — як «змінено», без зіставлення назв типів.

## 5b-3 — уточнення після дослідження
Руда в точці не стала: гра вибирає її при появі з тих, чия карта тепла в точці > 0 (TH.GL показує точку під кількома типами — що бачили). Тож точка ресурсу — під кожним можливим типом (тип — тип мітки гри з компонента спавнера: AzuriteOre, AzuritePickup…), з вагою (значення карти тепла). Геометрія карт тепла — з WorldGenerator мапи (m_WorldOriginOffset, m_WorldSizeInMeters), таблиця типів і група карт — звідти ж.
- Task 3a (видобувач): експорт світу мапи (Survival_1.umap), DT_ResourceTypes, групи карт тепла й самих карт, спавнерів і їхніх компонентів (замикання); normalize/resources.mjs — вибірка карти тепла (потік бітів палітри), записи { id, map, kind core|aux, type: тип мітки, group, weight, x, y, z }; точка без можливої руди — тип групи гри.
- Task 3b (сайт): шари ресурсів — типи міток гри (категорія легенди «Ресурси», іконки й назви гри); порівняння з TH.GL за місцем.

## 5b-4 — міста, малі мапи, Глибока пустеля (дослідження 22.10, збірка 2162777)
Рішення користувача (22.10): іконки — лише з текстур гри через ігрові зв'язки. Де гра має мітку мапи — її іконка; NPC — іконка фракції (`DT_FactionData.m_FactionIcon`, ключ = `m_Faction` рядка `CDT_NPCConfigs`, лише точний збіг; нема — текстура мітки NPC гри `T_UI_IconMapMarkerNpc`); ключ — іконка ключа-коду гри (`T_UI_IconPickupKeycode`) у кольорі ключа (`DT_InteractionKeyCodes.m_KeyColor`), назва — `m_DisplayName`; скрині й трупи — мітка гри `LootContainer` (одна на всі види, вид — назвою шару).
Знахідки:
- Id мап сайту = назви рівнів гри малими (`sh_arrakeen` = SH_Arrakeen, `cb_overland_s_08`, `cb_story_banditfortress01`, `overmap`, `deepdesert_1`) — без відповідності.
- Міста й малі мапи — World Composition: рівні мапи = усі .umap її теки (без Audio/Lighting/Foliage/LOD/VFX/Fog/Cinematics); зсуву нема (збіг із TH.GL 0 см). Точки: `DuneStaticMarkerActor` (тип мітки гри), `TemporaryLootSpawner`, `BP_PentashieldKey_C`, `BP_AiSpawnLocation_C` з `m_bIsStatic` і рядком `NPCType` з `DT_NPCConfigs_Named` (іменовані NPC; Харко 36 = TH.GL 36), точки ресурсів, вкладені блоки (`BP_TerrainBlockActor_C`, Бруд — Broodworks). Рівні контрактів/сюжету — окремо (з'являються лише в завданні) — Ruling: не беремо (TH.GL їх теж здебільшого не має) — ціна: кілька точок контрактів менше.
- Ресурси малих мап: група розподілу — з `DuneWorldGenerator` мапи (`DA_Placeable_Resources_DistributionGroup` без карт, Бруд — одна карта). Геометрії світу в генераторі нема → лише варіанти без карти (HeatmapName None).
- Ruling (усі мапи, і Хаґґа): точка ресурсу без жодної можливої руди не показується — гра там нічого не створить; група «Точки ресурсів без типу» зникає — ціна: якщо гра все ж щось там ставить, точки бракуватиме.
- Огляд (`overmap`): `BP_OvermapPoi_C` (22) — точки мап подорожі.
- Глибока пустеля: розкладка (`WorldLayoutSubsystem` у DefaultGame.ini: `Content` + `HeatMapSettings.ResourceDistributionGroup`) → `m_Clusters` (якір, `WLC_*`, варіант) → `m_Variations[варіант].TerrainBlocks` (блок `TerrainBlockDataAsset`, Location/Rotation, групи й перевизначення) → той самий обхід блоків, що в Хаґзі; світ = локальне + якір × 101600; геометрія карт тепла — генератор DeepDesert_1 (−51200, 24384 м). Розкладка 11 ↔ TH.GL 11: 133/254 місць до 3 м (інші розкладки ~0).
- Обсяг ГП: ~230 тис. точок з рудою на розкладку, «усі можливі руди» ≈ 1 млн записів на розкладку × 17 — у таблицю не кладемо.
### Task 4a: міста, малі мапи, огляд
Видобувач: рівні тек мап (експорт `levels`), `normalize/map.mjs` — мапи без регіонів (World Composition), NPC (`npc`, тип = id рядка NPC гри, назва — ключ рядка), ключі з назвою й кольором (розділ `keyCodes`), фракції (розділ `factions`: id, іконка); ресурси малих мап з їхньою групою; точки без руди — не пишемо. Сайт: групи й іконки за ігровими зв'язками (NPC → фракція, ключ → колір, лут → мітка LootContainer), перевірка покриття мап.
### Task 4b: Глибока пустеля
Видобувач: розкладки з ini, кластери, обхід → місця/лут/ключі за розкладками (`layout`), ресурси — блоки один раз (локальні точки + місця блоку) і розміщення блоків за розкладками; карти тепла розкладок — пакет. Сайт: точки ГП поточної (і вибраної) розкладки складаються на сервері з блоків і розміщень з кешем; руди — з карт тепла розкладки.
