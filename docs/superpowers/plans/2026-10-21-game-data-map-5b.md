# Мапа з файлів гри — план 5b

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** точки мапи з файлів гри з ігровими типами (без відповідності TH.GL) і розклад розкладок Глибокої пустелі з гри. Мапа лишається на TH.GL як основне, доки файли гри не покриють усе (ресурси, міста); до того мапа з файлів гри — друге джерело групи «Мапа» з порівнянням.

**Spec:** `docs/superpowers/specs/2026-10-21-game-data-drivers-design.md` §4.1, §4.6; план 5 (`2026-10-21-game-data-map.md`) Task 3; дослідження — side-session-notes/…/map-research.md («Plan 5b research»).

## Знахідки (збірка 2160922)
- Хаґґа: регіони `SOC_1/SubLevels/Survival_1_<Регіон>.umap` → `BP_TerrainBlockActor_C` (блок + групи + перевизначення вкладених) → `TerrainBlockDataAsset` (рівні блоку з групами, вкладені блоки) → актори рівнів. Прототип обходу збігся з TH.GL до сантиметра (печери 95/98, табори 425/435, аванпости 70/70, екоlab 14/14, уламки 13/13, січі 8/8).
- Тип точки — тип мітки гри (`CDT_FullscreenMapMarkers`, 225 рядків: назва з таблиці рядків, тег фільтра `MapMarkers.*` → група, текстура іконки). Іконка — файл awakening.wiki з іменем текстури (те саме правило, що для будівель). Точки без мітки — клас гри (`TemporaryLootSpawner` з типом контейнера, `BP_PentashieldKey_C`, `BP_VehicleSpawner_*`…).
- Розклад ГП: `DefaultGame.ini [CoriolisSubsystem]` — старт 2024-12-03 05:00, цикл 7 днів, `m_CycleSeeds` (122), регіональний зсув; номер = індекс у списку розкладок `WorldLayoutSubsystem`.
- Ресурси: групи точок загальні (`Minerals`, `Scrap`…); конкретний ресурс — карти тепла (`DT_ResourceTypes` + `DA_*DistributionGroup` → `HeatMapData`). Окремий етап.

## Global Constraints
- Файли гри й сирі експорти — лише в `GD_WORK`; у пакеті — лише похідні дані (координати, ігрові id, ключі перекладів). Без таблиць відповідності; типи — ігрові id.
- Робоча копія, міграції — додаткові й ідемпотентні; живий — лише після перевірки на `dune_preview`.
- Мапа TH.GL лишається основною, доки користувач не перемкне групу «Мапа».

## Review Focus
1. Блок, рівень чи вкладений блок, якого нема в експорті — розділ з помилкою (видобувач), не мовчки менше точок.
2. Новий патч змінює кількість точок на >50 % — розділ на утриманні (правило реєстру), а не порожня мапа.
3. Порівняння TH.GL ↔ файли гри за позицією (ключ — мапа й координати), тип — як «змінено», без зіставлення назв типів.

### Task 1 (5b-1): видобувач — рівні блоків і обхід
Files: `tools/game-extractor/export/Program.cs` (команда `levels`: стислий експорт акторів рівня й точок ресурсів; повні властивості для `BP_TerrainBlockActor_C`), `lib/raw.mjs` (список регіонів Хаґґи, описи блоків, замикання рівнів), `normalize/map.mjs` (обхід, світові координати, сайт = [Y, X] гри), `normalize/markertypes.mjs`, `normalize/ddschedule.mjs`, тести на обрізаних фікстурах.
- RED: обхід — трансформи (зсув рівня, поворот і масштаб блоку, вкладений блок), групи (за замовчуванням, перевизначення розміщенням), вимкнений вкладений блок; типи міток — назва (ключ таблиці рядків), група за тегом, текстура; розклад — індекс тижня й регіональний зсув.
- GREEN; прогін на збірці; звірка з TH.GL за позицією (≥95 % місць збігаються до 1 м).
- Розділи пакета: `markers` (точки Хаґґи й розкладок ГП: `{ id: '<мапа>@<y>:<x>', map, layout?, type, name?, x, y, z }`), `markerTypes`, `ddLayouts` (розклад).

### Task 2 (5b-2): сайт — мапа з файлів гри як друге джерело
Files: `server/lib/gamedata/drivers/thgl.mjs` (точки — записами для порівняння), `server/lib/gamedata/apply.mjs` (застосувачі `markers`, `markerTypes`, `ddLayouts` → таблиці), `server/lib/gamemap.mjs` (джерело точок з таблиць у формі TH.GL-даних мапи: групи з тегів гри, іконка — URL), `server/routes/map.mjs` (вибір джерела за основним групи «Мапа»), `src/lib/map/*` (іконка типу — картинка за URL поряд зі спрайтом), тести.
- RED: застосування `markers` дає точки за типами гри; `/api/map/source` з основним «файли гри» віддає групи гри й іконки-URL; порівняння TH.GL ↔ файли гри за позицією.
- GREEN; перевірка мапи на копії.
