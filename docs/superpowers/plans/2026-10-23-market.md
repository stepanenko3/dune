# Біржа (WTB / WTS) — план реалізації

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** оголошення «Куплю / Продам» з предметами з файлів гри, пошук, книга заявок і медіана, автоматичний збіг зі
сповіщеннями, угоди з листуванням і оцінками, модерація й заборона RMT.

**Architecture:** нова річ реєстру `listing` (items + content.mjs), свої таблиці біржі в `server/lib/market.mjs`,
маршрути `server/routes/market.mjs`; загальні сповіщення сайту `server/lib/notifications.mjs` + дзвоник у шапці.
Клієнт — розділ `market` (без роутера: zustand-вид + сегменти шляху), сторінки в `src/pages/market/*`.

**Tech Stack:** Node 22 + Express, Postgres/SQLite через `server/lib/sql.mjs`, vitest, React 18 + Tailwind + @snotax/ui.

**Spec:** `docs/superpowers/specs/2026-10-23-market-design.md`

## Global Constraints

- Робота лише в `../dune-market` (гілка `claude/market`); сервер — `ENV_FILE=…/market.env` (БД `dune_market`), тести —
  SQLite + `dune_market_testing`.
- Усі тексти — `t()` / `req.t` / `fail()` з українським ключем; переклади 13 мов у `locales/parts/market.<lang>.json`,
  `npm run i18n:merge` без `--clean`; `npm run i18n:extract` — 0 відсутніх.
- Альтернативи — картки поруч (`Choice`-кнопки, як у Access/EventEditor), без `<select>`.
- Телефон: `grid-cols-[minmax(0,1fr)]`, `break-words`, без `truncate` на важливому тексті, sn-input `size="lg"` (≥16px).
- Вкладки — сегменти шляху, фільтри — `useUrlParam`; крихти — `useCrumb`.
- Кожен новий мутуючий маршрут — рядок у `server/admin/describe.mjs`.
- Предмет продається, якщо є в довіднику гри і: `cat ∉ {contract, swatch}`, `kind ∉ {HideFromExchange, Solaris,
  Abilities, HalloweenCurrency}`, назва не заглушка (`junkName`).
- TTL — 1 / 3 / 7 / 14 / 30 днів (типово 7). Причини скарг: `rmt, scam, spam, wrong, abuse, other`.
- Ліміти відкритих: людина 30, гільдія 100. Частота на людину за годину: оголошень 30, пропозицій 60, повідомлень 120.
- Автоприховування: 3 відкриті RMT-скарги від різних людей. Оцінку можна змінити 14 днів. Сповіщення живуть 90 днів.

## Review Focus

1. Гільдійське (`guild`) оголошення не потрапляє чужим ні в стрічку, ні в книгу, ні в історію, ні в сповіщення про збіг.
2. Подвійне натискання / одночасні «Прийняти» на дві пропозиції, що разом більші за залишок — залишок не йде в мінус.
3. Заблокований на біржі не може писати нічого (оголошення, продовження, пропозиція, прийняття, повідомлення, оцінка).
4. Світ «Hagga-EU 7» і «hagga eu  7» — той самий світ для фільтра й збігу.
5. Минуле оголошення (строк) не з'являється в стрічці й не дає нових пропозицій, навіть якщо фонова задача ще не пройшла.

### Task 3: Стрічка, сторінка оголошення, книга, медіана, світи

**Files:** Create `server/routes/market.mjs`; Modify `server/app.mjs` (маршрути, `hubs.listing`, спам-ліміти, `CREATES`), `server/admin/describe.mjs`.

**Interfaces — Produces (HTTP):**
- `GET /api/market?scope=all|mine|guild&guild&side&gid&cat&region&world&min&max&fresh=1|3|7&sort=new|cheap|dear&status=open|all&limit&offset` → `{ rows: ListingRow[], total }`; `all` — лише відкриті, не минулі, не сховані, видимі.
- `ListingRow = { id, side, gid, qty, left, minQty, price, barter, pay, negotiable, region, world, server, status, expires, fresh, created, updated, item: ItemView, rep: Rep | null }`; `Rep = { avg, n, done }` (власник-людина; гільдія — за автором).
- `GET /api/market/:id` → `ListingFull = ListingRow & { place, contact: { site, nick? }, note, rights: { edit, manage }, matches: ListingRow[], deals: DealRow[], placeBase?: { id, title } }` (нік — лише з входом).
- `PUT /api/market/:id` (`base`), `POST /api/market/:id/close`, `POST /api/market/:id/renew { ttl }`, `DELETE /api/market/:id` (є угоди → 409).
- `GET /api/market/item/:gid?region&world` → `{ book: { buy: ListingRow[], sell: ListingRow[], barter: ListingRow[] }, stats: { median, p25, p75, n, source: 'deals'|'listings'|null }, history: { at, qty, price, region, world }[] }`.
- `GET /api/market/me` → `{ defaults: { region, world, server, nick } | null, ban: { until, reason } | null, worlds: Record<region, string[]> }`.
- `GET /api/market/stream` — SSE.

### Task 4: Збіг, угоди, листування, оцінки, репутація

**Files:** Modify `server/lib/market.mjs`, `server/routes/market.mjs`, `server/market.test.mjs`, `describe.mjs`.

**Interfaces — Produces:**
- Таблиці: `market_deals (id, listing_id, gid, side, maker, owner_kind, owner_id, taker, qty, price, barter, status, maker_done, taker_done, region, world, server, reason, created, updated, closed)`, `market_messages (id, deal_id, user_id, text, at)`, `market_ratings (deal_id, from_user, to_user, score, text, at, updated, PK(deal_id, from_user))`, `market_matches (a, b, at, PK(a,b))`.
- `matchesFor(listing, ctxView)`: протилежний вид, той самий gid, region, world_key, (server_key обидва — однакові), відкриті не минулі не сховані, ціни сумісні (buy.price ≥ sell.price, якщо обидві є), `left ≥ min` навзаєм, не той самий власник.
- HTTP: `POST /api/market/:id/deals { qty, price?, barter?, text? }` → `DealFull`; `GET /api/market/deals?state=active|done|all` → `{ rows: DealRow[] }`;
  `GET /api/market/deals/:did` → `DealFull = DealRow & { messages, me: 'maker'|'taker'|'owner'|'mod', canRate, myRating, theirRating }`;
  `PATCH /api/market/deals/:did` (maker, `offered`), `POST …/accept|decline|cancel { reason? }|done`, `POST …/messages { text }`, `POST …/rate { score, text }`;
  `GET /api/market/users/:login` → `{ rep: Rep, ratings: { score, text, at, side }[], listings: ListingRow[] }`.
- `DealRow = { id, listingId, gid, side, qty, price, barter, status, region, world, server, maker: Person, taker: Person|null, owner: Owner, makerDone, takerDone, created, updated }`.
- Сповіщення (`notify`): `market.match { listing, other, gid }`, `market.offer { deal, gid }`, `market.accepted`, `market.declined`, `market.cancelled`, `market.done` (друга сторона підтвердила), `market.message` (ref = deal), `market.rate`, `market.expired { listing, gid }`, `market.moderated { listing, action }`.

- [ ] Тести: нове «Продам» за 100 і наявне «Куплю» за 120 того ж світу → автор «Куплю» отримує `market.match`; повторне

  активна від тієї ж людини → 409; більша за залишок → 400. Accept двох пропозицій 6 + 6 при залишку 10 → друга 409.
  Обидва `done` → `status: done`, залишок −qty; залишок 0 → оголошення `closed`. Оцінка до `done` → 409; 6 зірок → 400;
  повторна змінює; репутація `{ avg, n, done }`. Повідомлення бачать сторони; стороння людина → 404. Медіана: три угоди
  100/110/130 → `median 110, source 'deals'`.
